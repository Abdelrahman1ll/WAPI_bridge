WAPI Bridge

نظام متكامل لربط واتساب عبر API، يدعم عدة مستخدمين بشكل مستقل.

المميزات

  • ربط حساب واتساب عبر QR Code
  • حفظ الجلسات في قاعدة بيانات PostgreSQL
  • إرسال رسائل عبر API خارجي آمن
  • نظام اشتراكات وحدود للرسائل
  • مصادقة عبر JWT و API Key
  • لوحة تحكم لإدارة الحساب
  • دعم متعدد المستخدمين (Multi-tenant)

إرسال رسالة عبر API

الطريقة: POST

الرابط: https://your-domain.com/api/external/send/:userId

الـ Headers المطلوبة

Authorization: Bearer YOUR_API_TOKEN
Content-Type: application/json

Body (JSON)

{
  "phone": "201xxxxxxxxx",
  "message": "مرحبا من WAPI Bridge!"
}

مثال بـ Node.js

const axios = require('axios');

const response = await axios.post(
  'https://your-domain.com/api/external/send/USER_ID',
  {
    phone: '201xxxxxxxxx',
    message: 'Hello from WAPI Bridge!'
  },
  {
    headers: {
      'Authorization': 'Bearer YOUR_API_TOKEN'
    }
  }
);

console.log(response.data);

مثال بـ Python

import requests

url = "https://your-domain.com/api/external/send/USER_ID"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
payload = {
    "phone": "201xxxxxxxxx",
    "message": "Hello from Python!"
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())

مثال بـ cURL

curl -X POST https://your-domain.com/api/external/send/USER_ID \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"phone": "201xxxxxxxxx", "message": "Hello!"}'

الاستجابة

نجاح

{
  "success": true,
  "message": "تم إرسال الرسالة بنجاح",
  "balance": 99
}

خطأ - واتساب غير متصل

{
  "success": false,
  "error": "الواتساب غير متصل. يرجى ربط الحساب أولاً."
}

خطأ - تجاوز حد الرسائل

{
  "success": false,
  "error": "لقد استنفدت باقة الرسائل الخاصة بك. يرجى تجديد الاشتراك."
}

متطلبات التشغيل

  • Node.js v16 أو أحدث
  • PostgreSQL
  • npm

طريقة التثبيت

  1. استنساخ المشروع: 
    git clone https://github.com/Abdelrahman1ll/WAPI_bridge.git
  2. تثبيت المكتبات: 
    npm install
  3. إنشاء ملف .env: 
    DB_HOST=localhost
DB_PORT=5432
DB_NAME=whatsapp
DB_USER=postgres
DB_PASSWORD=your_password
JWT_SECRET=your_jwt_secret
  4. تشغيل المشروع: 
    npm run dev
